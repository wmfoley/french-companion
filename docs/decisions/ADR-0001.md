# ADR-0001 — Expo-first proof of concept

**Status:** Approved by owner on 2026-11-10  
**Date:** 2026-11-10

## Context
PRD v0.1 section 10 describes a standalone React web prototype followed by an Expo Android app. Subsequent planning favored building with Expo from the outset, testing exercise flows on web first and Android thereafter, to reduce throwaway UI work.

## Decision
Use one JavaScript Expo/React Native project with Expo Router. Develop pure JavaScript exercise schemas and scoring in `src/core/`, with reviewed fixtures in `src/content/fixtures/` with automated unit tests. Run the initial educational prototype via Expo web; test on Android as soon as practical. Defer camera, OCR, Supabase, and AI until the exercise flow is validated.

## Consequences
- Reuse more UI and logic for Android.
- React Native Web is not identical to Android: TTS, keyboard behavior, accessibility, and navigation require device testing.
- Native OCR libraries may require an Expo development build and compatibility verification.
- No separate Next.js prototype is required.

## Reconciliation
PRD v0.1 sections 10, 12 and 16 now reference the approved Expo-first approach. Educational requirements and teacher-provided text are unchanged.

## FC-001 policy and boundary
Only scaffolding, minimal navigation, pure JavaScript grading, automated tests and documentation are authorized. The sample grader is case-insensitive, trims surrounding whitespace, uses canonical Unicode NFC normalization, and preserves accents, internal whitespace and punctuation. Original responses are retained. Later exercises require explicit policies suitable for their learning targets.
Teacher source text must remain verbatim; supplementary generated material must remain distinguishable and must never overwrite source content. No AI, OCR, authentication, Supabase or deployment is part of FC-001.

## Tooling limitations
ESLint 9 is deprecated but the current Expo React lint plugin's peer range excludes ESLint 10. Retain the compatible version for now. Audit reports 12 moderate advisories through Expo CLI/fingerprint and lint tooling, with no high/critical advisories. Do not force incompatible major downgrades. Reassess compatible upstream fixes separately.
